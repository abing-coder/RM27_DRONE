# OpenVINS 仿真接入补丁

来源为项目的 OpenVINS 子模块（GPL-3.0，作者 Patrick Geneva 等），保留其原有许可。
`openvins-static-zupt.patch` 修改两个已接受零速更新的返回路径，记录实际滤波更新时刻。
上游 `initialized()` 同时要求 `is_initialized_vio` 和 `timelastupdate != -1`；若机器人持续静止，
ZUPT 返回路径不更新后一字段，ROS 端就不发布 odom。上层等待健康 VIO 才解锁，会形成启动循环等待。
补丁只在真实静止初始化已成功、ZUPT 更新已被接受时设置该标记，不改变测量或初始化门限。

`build.sh` 在原始子模块上以 `git apply --check` 应用补丁，已应用时跳过；冲突时停止，
保留其他本地修改及未跟踪文件。父仓库保留原来的子模块提交指针，以免依赖无法获取的本地提交。
另一个修复位于 ROS2Visualizer：异步 IMU 回调创建的分离线程必须按值捕获 IMU 消息，不能引用回调栈；
空相机队列时不再创建工作线程，减少无效线程开销。相机/IMU 原始数据与滤波门限不因此改变。
相机队列锁只用于移动已到时的图像，KLT/MSCKF处理在解锁后执行，防止同一ROS回调组中的
图像回调等待锁而阻塞IMU接收。IMU订阅保留200条有界历史，与项目IMU发布和ESKF订阅一致；
采样时间、传播间隔和上层新鲜度检查仍然保留。处理耗时日志的延迟单位也统一为毫秒。
补丁沿用对应上游文件的 GPL-3.0-or-later 许可。
正常构建后子模块会显示已修改，具体变化对应本目录的可审查补丁。
